# Synthetic Dataset

This folder contains synthetic datasets created for the MMT-inspired Product Analytics case study.

## Datasets

- `dim_users.csv` — User-level demographic and behavioral segments
- `fact_app_events.csv` — Flight and hotel cross-sell product events
- `fact_bookings.csv` — Flight and hotel booking transactions

## Data Disclaimer

All data in this case study is synthetically generated for portfolio demonstration.

It does not represent MakeMyTrip's internal, proprietary, or confidential data.
