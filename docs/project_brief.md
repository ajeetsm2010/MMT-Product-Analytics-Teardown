# MMT-Inspired Product Analytics Teardown

## Project
Unlocking High-Margin Ancillary Revenue: Flight-to-Hotel Cross-Sell Funnel Optimization & Retention Analysis

## Business Problem

How can a travel platform increase hotel attachment after domestic flight bookings without adding friction to the flight booking journey?

## Objective

This case study analyzes a simulated flight-to-hotel cross-sell funnel to identify:

- Funnel drop-offs
- User cohort differences
- Product friction
- A/B experiment performance
- Incremental revenue opportunity
- Repeat booking and retention behavior

## Key Product Hypothesis

The primary bottleneck is decision friction during hotel cross-sell.

A long and uncurated hotel list may create choice overload, causing users to abandon the cross-sell experience.

## Proposed Product Intervention

Replace a generic hotel list with a small number of personalized recommendations and a contextual flight + hotel bundle incentive.

## Analysis Framework

1. Funnel Analysis
2. Cohort Analysis
3. A/B Testing
4. Revenue Impact
5. Retention Analysis
6. Product Recommendations

## Data Disclaimer

All data used in this case study will be synthetically generated for portfolio demonstration.

The analysis does not use or represent MakeMyTrip's internal or confidential data.
